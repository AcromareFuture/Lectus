# Lectus｜莱择

React 移动端电商与 Java API。暖白、炭黑和少量玫红，搭配杂志式选品封面、圆角商品卡、磨玻璃导航与弹层动画。

## 真实商品库与服务器中间件（2026-10-18）

首页、分类、搜索和 `SPU-` 商品详情已接入这批真实商品资料：60 品牌、250 SPU、876 组配色、2,732 SKU。图库、货号、配色与规格均保留来源关系；5 条跨配色可疑图片关联隔离待复核。未知售价、币种、自有库存保留空值，显示“待定价 / 暂未开售”，不使用来源报价伪造自己的售价。

Java 代码在本地；数据使用服务器已有 MySQL、Redis、MinIO。专用数据库和最小范围账号已创建，1,153 张去重图片及两档 WebP 共 3,459 个对象已导入。图片和模型使用内容哈希地址、长期浏览器缓存；目录 JSON 使用 Redis 短期缓存，导入后通过版本号失效。尚未部署本轮前后端应用。

```powershell
python scripts/remote_dev.py --bootstrap
./scripts/start-remote-backend.ps1
npm run dev -- --port 4205
```

第一条命令交互输入服务器凭证，开启本机隧道（MySQL 19906、Redis 19179、MinIO 19000），保持该进程运行。生成的专用凭证在忽略提交的 `.runtime/remote.json`，不含 root 凭证。不要将此文件放入发布包。Redis 当前没有 ACL 持久化配置，服务器重启后需重跑 bootstrap 恢复专用 ACL；缓存不可用时 API 回退数据库。

导入默认预检：`python scripts/import_catalog.py`；确认写入参数为 `--apply`。按源 ID 幂等更新，保留自有定价、库存与已审核模型。`--rollback <batch-id>` 仅隐藏本批商品，不删除历史、订单或对象。完整报告见 `work/catalog-import/`。

鞋类 40 款、109 配色已建独立模型槽位；目前未把通用鞋模冒充商品。预算为零，本机开源图生 3D 已试生成一款，体积约 0.43 MiB；纹理和鞋底未达到商城要求，保留独立实验页且未绑定商品。效果与限制见 [本地生成说明](resources/3d/LOCAL-GENERATION.md)。图生结果必须作为 AI 近似预览披露，不能保证鞋底、另一侧或尺寸还原。

## Java 后端第一版（历史记录）

Java 21 + Spring Boot 3.5，邮箱/密码登录。真实服务端流程位于「我的 → 账号与云端订单」，开发入口为 http://127.0.0.1:4205/#account 。

- 已接通注册、登录、退出、20款样例商品与规格、账号购物袋、地址、创建订单与取消订单。
- 服务端计算金额，事务扣减库存，幂等下单与取消；账号数据互相隔离。默认 H2 文件数据库重启保留数据；本轮开发已验证服务器 MySQL 配置。
- 早期商城入口使用本机演示数据；本轮主商品入口已切至真实来源库，旧演示记录与账号数据继续隔离。
- 未接入真实支付、物流、邮箱验证和密码找回。本次只完成本地开发与验证，未更新线上服务器。

在 `backend/` 运行 `.\run.ps1`，项目根目录运行 `npm run dev -- --port 4205`。详细启动、配置和部署说明见 [backend/README.md](backend/README.md)，接口说明见 [backend/API.md](backend/API.md)。

## 3D 鞋模体验

商品只展示与其 ID 明确绑定的专属模型，绑定表位于 `src/shoe-models.js` 的 `productModels`。目前没有任何在售商品的专属模型，因此详情保留商品照片，并提示「该款暂未提供专属3D模型」，不再用公共鞋模替代商品。

「查看独立3D演示」进入独立的 `#shoe-demo` 页面，无商品价格、规格或购买栏。进入时才加载 model-viewer 和约7.8MB的GLB，支持拖动旋转、触摸缩放、左右旋转按钮、缩放按钮、视角重置，以及午夜 / 海滩 / 街头三种材质。加载失败可重试或返回；不申请摄像头权限。后续真实模型逐款加入绑定表即可，无需给全部商品一起建模。

这是 Shopify 的独立示例鞋模，与当前商品的品牌、款式、规格无关，不代表商品实物，也不提供脚部追踪或AR上脚试穿。模型保持原文件，按CC BY4.0署名，页面提供来源和许可。来源说明见 `public/models/ATTRIBUTION.md`，后续接入方案见 `resources/3d/SDK-RESEARCH.md`。

## 多语言（v0.5.0）

- 设置页提供跟随系统、简体中文、English、日本語，可即时切换并在当前设备保存偏好。
- 自动根据浏览器语言选择中文、日文或英文；手动选择优先于系统语言。
- 翻译覆盖导航、设置、搜索、商品、购物袋、订单和常用交互提示；用户昵称、签名及社区内容保持原文。
- 金额继续以人民币 CNY 展示，语言选择不会触发汇率换算。

## 材质与交互动效（v0.4.0）

- 淡紫、冰灰和薄荷灰渐变；半透明商品卡、浮动导航、信息卡与玻璃弹层。
- 首页主商品配合 CSS 立体展台、透光环形装饰、投影和短暂抬升入场，未引入 WebGL 或外部模型。
- 按钮、链接和折叠标题共用按压与释放反馈，兼顾触摸、鼠标和键盘；拖动超过阈值会取消按压效果。
- 分类、社区话题与底部导航使用连续移动的选中背景；商品列表和页面切换有短过渡。
- 收藏与点赞回弹、规格选中反馈、数量变化、购物袋角标、表单聚焦与错误提示、消息与空状态反馈。
- 弹层和通知同时支持进入与退出，退出快照立即不可交互；关闭后可重新打开并恢复焦点。
- 详情支持左右滑动切换同图细节取景，原有分页按钮继续可用。
- 系统启用减少动态效果时关闭 CSS 动画并跳过 JavaScript 动画；未使用自动循环的商品漂浮或滚动劫持。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

浏览器打开 http://127.0.0.1:4200 。手机宽度下铺满屏幕，桌面显示品牌展示区与可操作的手机界面。

```sh
npm test
npm run build
npm run preview
```

`dist/` 是可部署的静态站点。可部署到域名根目录或子目录；路由使用 hash，不需要服务器重写规则。请通过 HTTP 服务访问，不要直接双击 `dist/index.html`。

## 产品边界

这是可交互的 React H5 前端原型，尚未编译为微信原生小程序。后续可使用 Taro 改造为 React 小程序，或在满足平台要求后使用 web-view 承载 H5。

本版参考得物的商城、社区、鉴别和交易入口组织前端流程，尚未达到其全部产品能力。账号页已经接入登录、库存和订单 API；其余旧入口仍为本机演示。实名认证、商家和商品审核、报价竞价、支付退款、专业鉴别、物流、搜索服务、图片存储、内容审核、实时私信和风控尚未接入。没有真实付款、发货或真伪结论。

## 目录

- `src/main.jsx`：页面、共享状态、交互与弹层。
- `src/domain.js`：购物袋、金额、搜索与地址校验逻辑。
- `src/data.js`：可替换的样例商品、社区与优惠券数据。
- `src/styles.css`：手机优先布局与基础材质。
- `src/motion.jsx`、`src/motion.css`：共用按压反馈、移动选中背景、弹层退出和材质动效。
- `public/images/`、`public/fonts/`：本地摄影与字体，无运行时外链依赖。
- `previews/`：浏览器实际页面预览。
- `VALIDATION.md`：已完成的验证与范围。
- `CREDITS.md`：摄影与字体来源。

建议正式开发时先接入商品、库存、账户和订单 API，再对接支付、鉴别与履约服务。价格、权限和订单状态转换必须由服务端校验。
