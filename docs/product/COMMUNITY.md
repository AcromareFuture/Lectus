# 用户社区

入口：`/#/community`。保留商城首页、商品、订单及既有导航效果，新增独立社区栏目。

## 已实现

- 推荐图文瀑布流、话题筛选、关注、视频、我的收藏和我的发布。
- 图文 1–9 张，JPG / PNG / WebP，每张不超过 10 MB；浏览器压缩转 JPEG，服务器重新编码，去除图片元数据。
- H.264 MP4 视频，不超过 50 MB、2 分钟及 4096 像素宽高。自动生成封面，视频流进入可视区静音播放，离开时暂停；详情支持原生进度与分段读取。
- 详情多图切换、点赞、收藏、评论、关注和删除自己的内容。发布、评论使用幂等键，重试不会重复创建。
- 沿用会员登录；未登录可浏览，写入操作需要有效会员身份。媒体只能被上传者用于自己的发布，未发布文件不公开。
- 发布与上传频率限制、文件格式检查、错误重试、加载及空状态、移动端布局和减弱动态效果适配。
- 六篇初始内容明确标记为莱择编辑部官方内容，使用项目已有图片。未伪造个人互动数。

## 技术位置

- 前端：`frontend/apps/storefront/src/Community.jsx`、`community.css`。
- API：`backend/services/member-service/src/main/java/com/heng/community/FeedController.java`、`FeedService.java`、`FeedMedia.java`。
- 数据：PostgreSQL Flyway 增量迁移 `V2__community_feed.sql`，五张社区表；原 V1 不改动。
- 网关：`/api/community/**` 转发会员服务。Nginx 上传专用路由限额 52 MB。
- 文件：`VIRIDAC_UPLOAD_DIRECTORY/community`，生产目录 `/opt/lectus-saas/data/uploads/community`；数据库只记录文件信息。
- 发布：`backend/deploy/publish-community.py` 备份数据库，切换独立版本目录，依次重启服务；健康检查失败回切原版本。
