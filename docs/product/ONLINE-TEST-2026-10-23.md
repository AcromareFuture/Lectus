## 已通过

- 三入口 HTTP 200，HTML 禁止缓存，三端 JS/CSS 返回正确内容类型。不存在的 JS 返回 404。
- HTTP 跳转 HTTPS，后台省略尾斜线时补齐。TLS 1.3 验证通过，证书匹配域名。
- Edge 公网浏览器实际打开三个入口并登录成功；用户订单、商家订单、平台订单都从线上后端读取。
- 用户和平台看到同一组 5 笔测试订单；官方旗舰店商家只看到自己店铺的 4 笔。
- 账号级购物车、跨店结算、合并付款、重复付款幂等。
- 商家发货、测试物流推进、用户确认收货；未发货退款申请、平台审核、退款凭证；订单取消。
- 三角色订单状态、支付凭证、物流事件、退款凭证一致。
- 未登录读取后台和用户订单均返回 401；跨店发货和商家调用平台管理操作返回 403。
- 商品目录图片通过同域 API 返回 image/webp。Nginx 的 API 路由优先于静态扩展名匹配，避免图片被误判为静态文件。
- 五服务健康检查 UP，systemd 开机启动已开启，后端端口只监听本机。
- 四个独立 PostgreSQL 数据库用于 identity/catalog/trade/member。迁入 250 商品、2,732 SKU、60 品牌；旧目录仅只读复制，新系统运行不依赖旧 MySQL。
- 本地发布前 member-service 121 项测试通过；前端 31 项通过；三端生产构建通过。本次前端补丁重新执行了前端测试与构建。

测试账号创建的记录保留在数据库中，便于复核。此次测试没有真实资金扣款或快递履约。

## 线上发现并修复

1. PostgreSQL 初始 ident 规则拒绝独立业务账号：已为四个指定数据库和账号增加仅 loopback 的密码认证规则，原配置有备份。
2. 平台概览日期写死，今天的订单未计入：改为北京时间的滚动 7/14 天，支持跨月、跨年，并定时更新日期。修复后概览显示测试成交 ¥2,979、3 单。
3. 个人中心仍调用已关闭的旧扫码订单接口：个人中心和商城订单现在复用相同组件与 mall/orders API。浏览器复测可读到新订单。
4. 替换“仅本次预览生效”“未接入认证”等过期提示；商家示例经营指标明确标注为展示样例。

## 范围和后续边界

- 当前是线上流程测试版本。支付、退款和物流使用模拟通道；商家经营图表、访客数、体验评分仍有展示样例，不应作真实经营报表。
- 发现频道的导入商品目录与可交易商城库存仍分开，导入商品不自动变成可售库存。
- 尚未完成压力测试、真实支付接入、真实短信/物流联调及正式生产验收。
- 本机直接 Python/curl 连接曾被重置；同机 Edge 公网访问和服务器对正式 HTTPS 域名的检查通过。未据此声称所有地域和运营商可达。
- 本次移动视口设置未实际改变 Edge 页面宽度，因此不计为手机适配验收。
- 证书到期：2027-01-21。HTTP-01 验证遭外层拦截，现通过手动 DNS-01 签发。虽然 certbot 有定时器，当前续期仍需人工更新 DNS TXT，尚未实现全自动续期。证书成功更新后已配置 Nginx reload hook。
