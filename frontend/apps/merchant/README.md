# Lectus 商家工作台

Vue 3 + TypeScript + Vite 的独立商家端前端预览，图标使用 @lucide/vue。采用用户端原有青蓝品牌色及柔和浮雕面板样式，支持桌面与移动端布局。

## 当前预览

- 经营概览：周期与图表指标切换、待办入口、热销商品、体验分、最近订单。
- 订单管理：搜索、状态筛选、详情、模拟发货、筛选结果 CSV 导出。
- 商品管理：搜索、分类与状态筛选、编辑、新增草稿、上下架。
- 营销活动：两组店铺券及暂停/恢复演示。
- 财务对账：示例结算明细及 CSV 导出，不包含真实资金操作。
- 店铺设置：本次预览的店铺资料表单、自动回复开关。
- 全局商品/订单搜索、消息面板、店铺信息和使用指南。

数据在 `src/data/demo.ts`。修改只保存在内存，刷新重置；演示经营指标与图表为独立样例，不作为财务依据。新增商品使用现有图片占位，图片上传、登录、权限、真实商品订单 API、多店、售后流程和支付结算尚未实现。当前不发起业务 API 请求。

## 启动与构建

在 frontend/ 下统一执行 `npm ci`，然后 `npm run dev:merchant`。开发地址为 http://127.0.0.1:4207/；`npm run build:merchant` 输出 apps/merchant/dist/。单应用命令也可在本目录运行，但依赖锁文件由 frontend/ 统一维护。

接口经本地 8080 网关访问；对应商家/平台业务接口尚待后端实现，开发代理可用不代表权限隔离已经完成。生产发布时配置各自域名或子路径，并转发 /api 到网关。
