# Lectus 平台运营后台

Vue 3 + TypeScript + Vite 独立应用，使用 Lucide 图标、ECharts 按需引入的折线图和现有 Lectus 品牌素材。

包含运营概览、商家管理、商品审核、订单查询、售后处理、结算对账、平台设置七个页面。支持筛选、搜索、详情、审核、停用、模拟售后处理、账单核对、CSV 导出和操作日志。概览的 7/14 天成交曲线支持成交额/订单数切换、悬停提示、触屏选择和方向键选日，坐标采用整刻度，汇总与图表使用同一组订单数据。

当前使用内存示例数据，刷新后重置。商家及商品审核、设置、日志均仅在预览中生效；售后操作不会发起真实退款，结算核对不会打款。未实现登录、业务权限、真实资质核验或消息发送服务。

在 frontend/ 下统一执行 `npm ci`，然后 `npm run dev:platform`。开发地址为 http://127.0.0.1:4208/；`npm run build:platform` 输出 apps/platform/dist/。单应用命令也可在本目录运行，但依赖锁文件由 frontend/ 统一维护。

接口经本地 8080 网关访问；对应商家/平台业务接口尚待后端实现，开发代理可用不代表权限隔离已经完成。生产发布时配置各自域名或子路径，并转发 /api 到网关。
